# Changelog

## v0.1.1 — README and onboarding redesign

### Changed

- Reworked the README around a 30-second overview and 5-minute quick start.
- Clarified the repository's positioning as a lightweight governance framework for long-horizon AI-assisted research.
- Added explicit "Who is this for?" guidance.
- Added a stronger distinction between:
  - controller / research orchestrator;
  - specialist workspaces;
  - execution agents;
  - evidence and Gates.
- Added three-level result review:
  - execution;
  - technical validity;
  - scientific validity.
- Added direct links and usage guidance for the three reusable templates.
- Added clearer explanations of the two methodology documents.
- Added design philosophy and lightweight-adoption guidance.
- Reduced the risk that the repository is mistaken for a giant prompt collection.

### Added

- `CHANGELOG.md`
- Text-only architecture diagram in README.

### Not yet added

- Agent Skills;
- automation scripts;
- benchmark/evaluation claims;
